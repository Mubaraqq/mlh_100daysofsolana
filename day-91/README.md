# Day 91: Make Your Launch Public

## Description

Connected the vault program (deployed on devnet) to a React frontend. Deposit and withdraw buttons call the program's instructions through the connected Phantom wallet.

## What Was Connected

- Vault program ID: Ex9Jpn1RF4uUP24anLNrP8XPuTcWF9VPpdftqcQ7dRJX
- Codama-generated TypeScript client for deposit and withdraw
- Wallet Standard wallet as signer
- useSendTransaction for building and sending transactions
- Vault PDA derived from ["vault", authority.pubkey]

## What I Learned

- The Codama client expects a TransactionSigner, not a plain address
- createWalletTransactionSigner from @solana/client wraps a Wallet Standard wallet into a signer
- The SAME signer instance must be used as authority AND fee payer. Two different objects for the same address throws "Multiple distinct signers"
- Deposit moves SOL from your wallet to your vault PDA
- Withdraw moves SOL from your PDA back to your wallet, signed by the program using seeds

## Full Stack Now

- Rust vault program on devnet
- IDL published on-chain
- Typed TypeScript client generated by Codama
- React frontend with Wallet Standard connection
- Deposit and withdraw calls from the browser
